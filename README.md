# UniformHub — Vue Student Uniform Request Portal

UniformHub is a responsive Vue 3 + Ionic Vue portal for students and the Marketing Office. It includes authenticated dashboards, uniform requests, status management, reusable registration invitations, inventory and size controls, profiles, password updates, and printable inventory reports.

## Run locally

Requirements: Node.js 22+ and npm 11+.

```bash
npm install
npm start
```

Open `http://localhost:4200/student/login` or `http://localhost:4200/marketing/login`.

Production build:

```bash
npm run build
```

Vite writes the deployable site to `dist`. Configure the host to send unknown routes to `index.html`.

## Supabase configuration

Copy `.env.example` to `.env.local` and set:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

Only the publishable key belongs in the browser application. Never place a Supabase secret or service-role key in any `VITE_` variable.

Apply the SQL migrations in `supabase/migrations`, then deploy the Edge Functions:

```bash
npx supabase functions deploy student-login-lookup
npx supabase functions deploy invite-register
```

The browser uses Supabase Auth and all authorization remains enforced by database RLS, PostgreSQL functions, and server-side invitation validation.

## Vue structure

- `src/App.vue` — Ionic Vue application root
- `src/router.ts` — Vue Router routes and authentication guard
- `src/views/LoginView.vue` — student and Marketing Office login
- `src/views/PortalView.vue` — dashboards and portal pages
- `src/components/RequestTable.vue` — reusable request table
- `src/stores/portal.ts` — reactive Supabase data and actions

The fixed pickup location is the school campus. Student and Marketing accounts can be created only through reusable, expiring invitation links generated by an authenticated Marketing Office user.
